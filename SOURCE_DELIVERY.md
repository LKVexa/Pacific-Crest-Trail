# Source and complete local distribution

This source checkout is for review and development. Large route, map, photo and public-provider archives are delivered in the corresponding complete local distribution, not in this checkout. No remote release asset location is asserted here.

To run the application, extract EVERY independently extractable distribution ZIP into the same destination. Each part contributes files under Trail Dossier/. Keep that directory together and run Start-Hike.cmd on Windows with Python 3.9+ (sqlite3), PowerShell/.NET Framework WPF and the installed Microsoft Edge WebView2 Evergreen Runtime. The existing house-browser provisioner retrieves the pinned SDK from official NuGet on first preparation; Microsoft SDK/runtime download caches are excluded under their own licensing rules. After preparation, all packaged maps and photographs are local. This release starts a new private hike; it contains no campaign history or browser profile.

For a runnable development checkout, copy the content/ directory and immutable browser/ runtime assets from the matching complete distribution into this source checkout, preserving its sealed runtime files. Do not copy another user's data/ or browser/workspace/. Read LICENSE, LICENSES.txt, NOTICE and browser licensing notices before redistribution. Public-provider imagery/source credits remain in the complete content catalog.

Each delivery manifest lists repository-relative paths, original byte lengths and SHA-256 hashes. The runtime integrity seal is unchanged. The browser package inventory is regenerated only for these clean publication copies. Test source and approved frozen fixtures are included; generated test runs, private keys, logs, evidence reports, backups, exports and verification reports are excluded. The donor Technical Institute auxiliary application and operational reports are excluded from this clean dossier edition; its safe public notices remain.
